1) ไปที่ Firebase Console → Project Settings → General → Your apps (Web) แล้วเอา config มาใส่ในส่วน firebaseConfig ด้านล่างนี้
2) ใช้ Cloud Firestore collection ชื่อ display document ตาม Display ID (เช่น main) ให้ ESP32 ดึงค่าจาก Firestore หรือจาก Cloud Function ก็ได้
3) ระบบจะบันทึกประวัติการส่งคำสั่งไว้ 15 วันล่าสุดใน subcollection logs ของแต่ละป้าย
